# Chloe Jeong · Portfolio

Personal portfolio website with an interactive 3D figure-skating rink (three.js).

- `index.html` – page shell
- `content.js` – all site text and data (edit here)
- `site.js` – page sections, pop-ups, navigation, project case studies
- `experience.js` – the editorial Experience section
- `rink.js`, `character.js` – the 3D rink and skater
- `style.css` – colours, type and layout
- `assets/` – photos, videos and logos

Open `index.html` through a local server (e.g. `python3 -m http.server`) or publish with GitHub Pages.
